# Capstone Presentation Kit

**Asset Security Dashboard** · Cyber Ready Clinic · v2 planned for about 4:35, under five minutes

This folder contains the presentation materials for the [Asset Security Dashboard](https://github.com/ammaarrehman/asset-security-dashboard) capstone. The files use only fictional nonprofit demo data.

## Current presentation (v2, local release pending owner approval)

A coordinated visual redesign of the deck and the application is on the local `redesign/visual-overhaul` branch. The v2 deck is a six-slide talk of about 4 minutes 35 seconds. The words on each slide are what the presenter says, and each slide is laid out around one subject: a cover screenshot, a plain device list, a four-step graphic, a before-and-after of a real record, the recorded demo, and a short conclusion. The original files below are unchanged and serve as the backup.

- [Download the current PowerPoint](Asset_Security_Dashboard_CRC_Capstone_v2.pptx): six editable slides, speaker notes, and the embedded recorded demo on slide 5. Every slide reads correctly without playing anything.
- [Demo recording](media/Demo_Recording.mp4): the 94-second recorded demo (1920 × 1080, H.264), from a real browser session of the redesigned app, with the key moments magnified for the projector. Also embedded on slide 5.
- [Presenter guide v2](Presenter_Guide_v2.md): what to say, what to point at, demo cues, timing, glossary, questions, a video playback check, a fallback plan, and a rehearsal checklist.
- [Slide preview v2](Slides_Preview_v2.png) and `slides/`: rendered slides (1920 × 1080).
- [PDF fallback](Asset_Security_Dashboard_CRC_Capstone_v2.pdf): static slides; play the recording separately if needed.
- [Live demo QR v2](Live_Demo_QR_v2.png): decodes to the public dashboard URL.
- `Offline_Presentation_Package_v2.zip`: everything needed to present without internet access (deck, PDF, demo video, guide, preview, QR, sample CSV). It is generated by `npm run package` in `source/` and not stored in the repository, because every file in it is already here.
- `source/`: the deck generator and helpers. `npm install && npm run build` builds the deck; `npm run record` records the demo video; `npm run walkthrough` rehearses the demo and checks its numbers. See the end of the presenter guide. The two earlier motion clips (`media/Trace_Diagram.mp4`, `media/Status_Change.mp4`) are kept but no longer used in the deck.

## Presenting

1. Download the current v2 PowerPoint from this repository and open it in PowerPoint or Keynote.
2. Review the v2 presenter guide, test video playback offline on the presentation computer, and rehearse the complete talk with a timer. The 4:35 plan is a budget, not a measured personal delivery.
3. Open the [live dashboard](https://ammaarrehman.github.io/asset-security-dashboard/) and choose **Reset demo** before presenting.
4. Have the sample file [sample-assets.csv](../../public/sample-assets.csv) ready if demonstrating CSV import.
5. If playback fails, use the PDF and standalone recording, or explain the before-and-after on slide 4.

The dashboard displays recorded security-hygiene information entered by a user. It does not scan devices or independently verify their security.
