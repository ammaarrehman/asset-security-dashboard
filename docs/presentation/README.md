# Capstone Presentation Kit

**Asset Security Dashboard** · Cyber Ready Clinic · approximately 5 minutes 30 seconds

This folder contains the presentation materials for the [Asset Security Dashboard](https://github.com/ammaarrehman/asset-security-dashboard) capstone. The files use only fictional nonprofit demo data.

## Presentation files

- [Download the PowerPoint (6 slides)](https://raw.githubusercontent.com/ammaarrehman/asset-security-dashboard/main/docs/presentation/Asset_Security_Dashboard_CRC_Capstone.pptx) — editable presentation with embedded speaker notes and QR code
- [Presenter guide](Presenter_Guide.md) — talk track, timed live demo, checklist, fallback, and expected questions
- [Slide preview](Slides_Preview.png) — a montage of the six slides
- [Live demo QR](Live_Demo_QR.png) — QR graphic linking to the public dashboard

## Presenting

1. Download the PowerPoint from this repository and open it in PowerPoint or Keynote.
2. Review the presenter guide and practice the recorded patch-status change.
3. Open the [live dashboard](https://ammaarrehman.github.io/asset-security-dashboard/) and choose **Reset demo** before presenting.
4. Have the sample file [sample-assets.csv](../../public/sample-assets.csv) ready if demonstrating CSV import.
5. If Wi-Fi fails, use the existing screenshots in the PowerPoint rather than spending presentation time debugging.

The dashboard displays recorded security-hygiene information entered by a user. It does not scan devices or independently verify their security.
