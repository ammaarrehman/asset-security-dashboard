## Presenting

1. Download the current v2 PowerPoint from this repository and open it in PowerPoint or Keynote.
2. Review the v2 presenter guide, test video playback offline on the presentation computer, and rehearse the complete talk with a timer. Aim for 3:20 to 4:00. The 3:29 plan is a budget, not a measured personal delivery.
3. Use the embedded 73-second recording for the preferred talk. If choosing a live demonstration, open the [live dashboard](https://ammaarrehman.github.io/asset-security-dashboard/) and reset its fictional demo data first.
4. Have the sample file [sample-assets.csv](../../public/sample-assets.csv) ready if demonstrating CSV import.
5. If playback fails, use the PDF and standalone recording, or explain the before-and-after on slide 4.

The dashboard displays recorded security-hygiene information entered by a user. It does not scan devices or independently verify their security.
